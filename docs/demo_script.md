# Two-minute demo

1. **S&OP scorecard.** "This is the planning meeting on 23 November. Five decisions, each linked to its evidence. The
   table is planning health against demo targets."
2. **Forecast accuracy.** Point at the first chart. "Summed, the sensing model looks better. At SKU level, where we commit
   stock, the consensus plan is twice as accurate. Same data, opposite answers; we decide at SKU level." Then the
   trade-off chart: "Removing the plan's 5% bias saves excess stock but costs service."
3. **Feed observability.** "One feed never arrived: coverage, not error. One week of actuals was nine days late. And a
   backfill made with actuals in hand would have looked almost perfect: the as-of rule excludes it, and a test fails the
   build if anything like it is ever scored."
4. **Capacity.** Site Beta selected. "Three weeks over capacity on the base plan. Constrained, that's 16,500 units that
   slip unless we add hours."
5. **Inventory.** "Four positions where the forecasts disagree. Recent actuals side with the sensing model on both: cut
   NV-S210, expedite NV-H330 at Gamma."
6. **Data checks.** "Everything the pipeline handled, and the rules it enforces on every build."
